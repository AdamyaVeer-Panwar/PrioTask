# PRIOTASK

Priority Based Academic Workflow Simulator

## Team

- Adamya Panwar
- Mamta Patel
- Avighnn Chauhan

## Project

PRIOTASK is a Data Structures based academic workflow simulator developed in C.

The project uses:

- Linked List for task registry
- Queue for regular tasks
- Priority Queue for urgent tasks
- Stack for completion history

## Technology

- C
- Standard C Library
